Privacy Policy – CCTV Acer

Last updated: 24 November 2026

CCTV Acer is used only by its owner to manage private live broadcasts on the owner's own YouTube channel.

Data accessed

With the owner's permission, the tool uses the YouTube Data API to create, bind, list, and end the owner's own live broadcasts and live streams. It does not access any other user's data.

Storage and sharing

The OAuth token is stored only on the owner's own server, readable only by the owner's account. No data is sold, shared, or transferred to third parties, and no analytics or advertising are used.

Revoking access

The owner can revoke access at any time at myaccount.google.com/permissions.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
